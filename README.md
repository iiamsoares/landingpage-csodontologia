# Landing page CsOdontologia 

Landing page desenvolvida para a clínica **CS Odontologia Especializada** como parte da disciplina **Projeto Integrador III**.

## Sobre o projeto

Este site foi criado por mim e meus colegas de sala na faculdade, com foco em contribuir para o comércio local por meio de uma presença digital profissional para a clínica.

A captação do cliente foi realizada pelos gerentes de requisitos da equipe. Durante o levantamento, identificamos a necessidade de um site que:

- Informe e instrua melhor os leads;
- Reforce a credibilidade da clínica;
- Apresente os serviços de forma clara e acessível.

## Objetivo

Construir uma landing page moderna, responsiva e objetiva para apoiar a comunicação da clínica com potenciais pacientes.

## Funcionalidades

- Seção inicial com chamada para ação (CTA);
- Lista de especialidades odontológicas;
- Depoimentos de pacientes;
- Carrossel com imagens da clínica;
- Mapa de localização incorporado (Google Maps);
- Botão flutuante para contato via WhatsApp;
- Links para redes sociais.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (vanilla)

## Estrutura do projeto

```text
refatoração-csodontologia/

```

## Como executar

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` no navegador.
